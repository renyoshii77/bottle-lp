// FEATURES — 機能一覧

現場に必要な機能、
すべて入っている。

AUTO CALC

🧮 全自動計算

PK数・後端数・戻し本数（4本単位）が入力と同時にリアルタイムで計算される。計算ミスはゼロ。

CARRY FORWARD

🔗 前端数の自動引き継ぎ

登録ごとに次ロットの前端数が自動でセットされる。引き継ぎ漏れがなくなる。

EDIT

✏️ 後から編集できる

ロス・本数・担当者名など全項目を後から修正可能。スプレッドシートへの上書きも自動。

NORMALIZE

↩ 前端数の正規化

前端数が1pk分以上入力された場合、ボタン1つで自動変換。PK数も+1される。

AUTO SAVE

💾 データ自動保存

ホーム画面に戻ってもデータは消えない。RESETボタンを押すまで保持される。

MULTI BOTTLE

🍶 複数瓶に同時対応

5K・7K・9K・13K瓶を同時に記録可能。カスタム瓶の追加もできる。

// CALCULATION — 計算ロジック

計算式は、すべて透明。

どの数字がどう計算されているか、きちんとわかる設計になっている。

📦 PK数

(製造予定数量 − 前端数)
÷ 1pkの本数（端数切り捨て）

例：9K瓶 7800本 前端数40本
(7800-40) ÷ 140 = 55pk

※前端数が満タン（perPk以上）の場合は0本+PK+1として計算

🔢 後端数・次前端数

後端数 = (製造予定数量−前端数) の余り
次前端数 = 1pk本数 − 後端数 − ロス

例：7760 ÷ 140 = 余り60本
次前端数 = 140 − 60 = 80本

次ロット開始時に前端数へ自動引き継ぎ

↩ 戻し本数（4本単位）

4 − (製造予定数量 + ロス) ÷ 4 の余り

例：6685本 ロス3本
6688 ÷ 4 = 余り0 → 戻し0本

6685本 ロス0本
6685 ÷ 4 = 余り1 → 戻し3本
